Thiết lập tài khoản quản trị

Chỉ làm một lần duy nhất trên thiết bị đầu tiên. Bạn cần một GitHub Personal Access Token để website lưu được thay đổi.

Cách tạo token (khoảng 1 phút)
  1. Mở github.com → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Đặt tên: hunghiephuy-admin. Ở mục Repository access chọn Only select repositories → chọn repo Hunghiephuy.
  3. Ở mục Permissions → Repository permissions → Contents chọn Read and write.
  4. Bấm Generate token → copy token rồi dán vào ô bên trên.
